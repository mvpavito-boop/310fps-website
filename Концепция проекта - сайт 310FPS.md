## 🎨 1. Веб-дизайнер — Визуал и UX/UI

### Стиль и атмосфера

Дизайн должен передавать атмосферу «лаборатории-мастерской» — не хаотичный гейминг и не стерильный Apple-минимализм, а нечто среднее: тёмная, точная, технологичная среда. Представьте интерьер реальной мастерской по сборке высокоточных механизмов: чёрный стол, подсветка рабочей зоны, металл и стекло. Всё на своём месте. Порядок как философия.

**Визуальная атмосфера:** «Мрачный перфекционизм». Не агрессия киберпанка, не кричащий RGB — сдержанная уверенность эксперта.

### Референсы и чем не нравится Digital Razor

- **Перегруженная навигация:** у DR десятки категорий, пользователь теряется — у нас максимум 3 клика до нужного результата.
    
- **Пассивные баннеры вместо живых видео:** у нас hero-блок с таймлапсом сборки.
    
- **Нет формулы цены и сравнения с розницей:** у нас это центральный элемент доверия.
    
- **Отзывы без верификации и без привязки к конкретному ПК:** у нас каждый отзыв с фото машины.

## 💻 2. Разработчик — Техническая часть

### Стек технологий

- **Frontend:** Next.js 14 (App Router) + TypeScript — SEO из коробки, серверный рендеринг для карточек сборок.
    
- **Стилизация:** Tailwind CSS + shadcn/ui — быстрая разработка, кастомизация без боли.
    
- **Анимации:** Framer Motion — scroll-triggered анимации, микро-взаимодействия в конфигураторе.
    
- **3D-элементы (опционально):** Three.js / React Three Fiber — для будущего 3D-конфигуратора.
    
- **Backend:** Next.js API Routes + PostgreSQL (Supabase) — хранение сборок, заявок.
    
- **CMS для каталога:** Sanity или Strapi — редактируемый каталог сборок без программиста.
    
- **Хостинг:** Vercel (бесплатный tier достаточен для старта) + Cloudflare CDN для видео.
    

### Логика конфигуратора — обработка несовместимости

- **Подход: фильтрация, а не предупреждение.** Несовместимые детали автоматически скрываются из списка, а не подчёркиваются красным. _Пример: выбрал Socket AM5 CPU → в списке материнских плат остались только AM5-платы._
    
- **Ручное вмешательство:** При критической несовместимости (вручную переключил) — жёлтый баннер: «Эти компоненты несовместимы» + кнопка «Автоисправить».
    
- **Хранение данных:** Совместимость хранится в JSON-матрице на бэкенде: `{ cpu_socket, mb_socket, ram_type, pcie_version }` — обновляется при добавлении новых позиций.
    

### Интеграции

- **База данных сборок:** PostgreSQL через Supabase — сохранение конфигураций по UUID-ссылке (без регистрации).
    
- **Telegram-уведомления:** Telegram Bot API — при отправке заявки менеджер получает сообщение с конфигурацией и контактом в ЛС.
    
- **Цены DNS/Ситилинк:** Парсинг через Python-скрипт раз в сутки (cron) → сохранение в БД. Показываем розничную цену «в рознице: Х₽» рядом с нашей ценой.
    
- **Яндекс.Карты:** Виджет для адреса мастерской в разделе контактов.
    
- **Видеохостинг:** Cloudflare Stream или YouTube embeds — для таймлапсов сборок и стресс-тестов.

### УТП — почему мы, а не конкуренты или сетевой магазин

- **Именной мастер** — не «сотрудник компании», а конкретный человек с именем в паспорте ПК. Личная ответственность.
    
- **Радикальная прозрачность** — видео вашей сборки, все коробки и чеки на руки, открытая формула цены.
    
- **Протокол, а не слова** — 24-часовой стресс-тест как стандарт (не опция), андервольт CPU/GPU, Thermal Grizzly Kryonaut в каждой сборке.
    
- **Консультация на вырост** — подбираем платформу с учётом апгрейда через 2-3 года, бесплатно.
    
- **Пожизненная поддержка в Telegram** — не call-центр, а прямая связь с мастером.
    

### Блоки доверия на главной странице (приоритет)

1. **Счётчик:** 2000+ собранных ПК | Рейтинг 4.9 | 495 отзывов.
    
2. **Видеофон hero-блока:** таймлапс реальной сборки (5-8 сек, loop, без звука).
    
3. **Три обещания под заголовком:** «Видео сборки • Стресс-тест 24ч • Прозрачная цена».
    
4. **Паспорт ПК как физический артефакт:** фото реального паспорта с результатами тестов.
    
5. **Видео-отзывы клиентов** с фото их машин и городом.
    
6. **Прямая ссылка на Telegram-канал** как proof of life.
    

## 🤝 4. Менеджер по продажам — Конверсия и воронка

### Идеальный сценарий воронки

**Оптимальная воронка:** конфигуратор → цена → «Обсудить с мастером» → закрытие в Telegram/WhatsApp. _НЕ онлайн-оплата на старте — слишком высокий чек (150-500к₽) требует личного контакта для закрытия сделки. Онлайн-оплата = только для готовых сборок «в наличии»._

1. **Шаг 1:** Клиент собирает конфигурацию через конфигуратор или выбирает готовую сборку.
    
2. **Шаг 2:** Видит итоговую цену с разбивкой (детали / работа / гарантия).
    
3. **Шаг 3:** Кнопка «Обсудить с мастером» → открывается Telegram с предзаполненным сообщением: _«Интересует сборка [название], бюджет ~[сумма]»_.
    
4. **Шаг 4:** Менеджер отвечает по скрипту консультации, закрывает на предоплату 30%.
    
5. **Шаг 5:** Сборка → видеофиксация → отправка → отзыв (скрипт трёх касаний).
    

### Допродажи (Upsell/Cross-sell) на этапе заказа

- **Расширенная гарантия** (+1 год, итого 2 года) — `+3 000₽`
    
- **Установка ОС + активация Windows 11 Pro** — `+2 500₽`
    
- **Кастомная цветовая схема подсветки** — `+1 500₽`
    
- **Курьерная доставка с расширенной упаковкой и страховкой** — `+500-1500₽` в зависимости от региона
    
- **Игровая периферия** из «рекомендованного» списка (ссылки на DNS/Ситилинк) — партнёрский формат.
    

### Сохранение лидов — горячие и холодные

- **Кнопка «Сохранить сборку»:** генерируется уникальная ссылка без регистрации. Ссылка сохраняется в браузере (localStorage) + опционально «отправить на email/Telegram».
    
- **Exit-intent попап** при уходе со страницы конфигуратора: _«Сохранить сборку? Пришлём ссылку в Telegram»_ — минимальное трение.
    
- **PDF-смета:** кнопка «Скачать спецификацию» — генерируется PDF с конфигурацией, ценами и контактами мастерской.
    
- **Триггер ретаргетинга:** если пользователь собрал конфигурацию, но не отправил заявку — через 24ч Telegram-бот (если оставил контакт) присылает напоминание
