## Negative prompt

```
neon colors, cyberpunk, RGB gamer aesthetic, cluttered background, cartoon, illustration, oversaturated, cheap, plastic look, smiling too much, messy workshop, fluorescent lighting, stock photo, watermark, text, logo errors, deformed hands, extra fingers
```

## Рекомендации

- **Соотношение сторон:** 3:4 или 4:5 — удобно для карточки мастера.
- **Разрешение:** минимум 1024×1280 px.
- **Модели:** FLUX.1 Pro / FLUX.2 Pro / Midjourney v7 / Ideogram 3.
- **Путь в проекте после генерации:** `/public/images/about-master.jpg` или `/public/images/about-master.webp`.
