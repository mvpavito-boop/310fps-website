# Full Page Redesign Checklist — 310FPS

Before finishing a full-page visual redesign, verify every visible module.

## Required module audit

Codex must inspect the route and list all visible modules.

For each module:

- identify current component/file
- decide whether it needs visual redesign
- apply 310FPS Design System V4
- preserve backend/data behavior
- verify responsive behavior if possible

## Completion rule

A full-page redesign is complete only when:

- hero follows 310FPS style
- navbar follows 310FPS style
- product/catalog cards follow 310FPS style
- filters/controls follow 310FPS style
- section headings follow 310FPS style
- CTA blocks follow 310FPS style
- footer follows 310FPS style
- mobile/tablet/desktop layouts are checked
- no major module looks like default Tailwind UI
- no major visible module remains unchanged without explanation

## Report format

At the end, Codex must return:

| Module | Files changed | Visual result |
|---|---|---|

Also include:

- checks run
- backend untouched confirmation
- remaining visual issues
