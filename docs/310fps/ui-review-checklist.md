# 310FPS UI Review Checklist

Before considering a UI task complete, verify:

## Brand

- [ ] Looks like 310FPS Custom Lab
- [ ] Premium dark tech aesthetic
- [ ] Not generic SaaS
- [ ] Not cheap gaming chaos

## Layout

- [ ] Strong hero section
- [ ] Clear section hierarchy
- [ ] Good spacing rhythm
- [ ] No cramped areas
- [ ] No random gaps
- [ ] Responsive layout checked

## Typography

- [ ] Hero heading is powerful
- [ ] H2/H3 hierarchy is clear
- [ ] Body text is readable
- [ ] No weak default font feel

## Components

- [ ] Buttons look custom
- [ ] Cards have depth
- [ ] Navigation feels premium
- [ ] Footer is clean and structured

## Visual depth

- [ ] Background has subtle depth
- [ ] Glow is controlled
- [ ] Accent color is intentional
- [ ] One focal point per screen

## Technical safety

- [ ] Backend untouched
- [ ] API behavior untouched
- [ ] No schema changes
- [ ] No auth/payment changes
- [ ] Build/lint/typecheck run if available

If any checkbox fails, continue refining.
