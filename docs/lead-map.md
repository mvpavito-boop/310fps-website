# Карта заявок 310FPS

## API

Все формы отправляют заявки в `POST /api/telegram/lead`.

Обязательные поля:

- `name` — имя клиента
- `phone` — телефон или Telegram

Опциональные поля:

- `message` — задача и комментарий клиента
- `source` — технический источник заявки
- `model_id` — модель, пресет или контекст
- `model_title` — человекочитаемый контекст
- `price_from` — цена или итоговая стоимость
- `config` — комплектующие/характеристики

Сообщение для Telegram форматируется в `src/lib/lead-message.ts`.

## Источники

| Source | Где возникает | Что уходит в Telegram |
| --- | --- | --- |
| `home_quick_consultation` | Главная, блок `Начните за 30 секунд` | Имя, контакт, выбранная задача, контекст блока |
| `home_stages_modal` | Главная, модалка из блока этапов | Имя, контакт, комментарий, контекст `Как мы работаем` |
| `contacts_page` | Страница контактов | Имя, контакт, задача, комментарий |
| `contacts_lineup_{id}` | Страница контактов с `?model={id}` | Имя, контакт, задача, комментарий, интересующая LAB Series |
| `configurator` | Конфигуратор | Имя, контакт, итоговая стоимость, список выбранных комплектующих |
| `lineup_{id}` | Страница LAB Series | Имя, контакт, модель, цена от, комплектующие |
| `catalog_{id}` | Страница готового ПК / каталог | Имя, контакт, модель, цена, комплектующие |

FPS в играх не отправляется в заявки. Он остается только на сайте как маркетинговый/информационный блок.

## Telegram Support Bot

Текущая рабочая схема: заявки отправляются через Support-бота `lab310fps_support_bot` в `TELEGRAM_CHAT_ID`.

Обязательные переменные:

- `TELEGRAM_CHAT_ID`
- `TELEGRAM_BOT_TOKEN`

Опционально для Direct Messages канала:

- `TELEGRAM_DIRECT_MESSAGES_TOPIC_ID`

Если `TELEGRAM_DIRECT_MESSAGES_TOPIC_ID` не задан, API отправляет заявку в обычный `TELEGRAM_CHAT_ID`.
